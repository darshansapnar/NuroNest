## Guided narration status

No spoken guided-narration audio exists for any of the 6 meditation
practices or the Evening Calm feature yet. Every practice's `audioUrl` is
`null`, and the session UI honestly shows "Guided meditation — coming soon"
rather than implying narration is available. **Guided narration has NOT
been added yet — this file only ever records background ambience tracks
until that changes.**

track and `backgroundAudioUrl` set accordingly:
